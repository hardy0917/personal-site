個性積極主動，喜歡把問題拆開、一步步解掉。從課堂專題到銀行的金融交易系統，我在意的是寫出穩定、別人接手看得懂的程式。

畢業後進入合作金庫資訊部，實際接觸金融交易系統，學會在嚴謹的流程裡用 Java 修改功能、用 Git 與團隊協作。接下來，我希望參與更多跨平台或大型專案，持續精進技術。
